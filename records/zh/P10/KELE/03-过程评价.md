# P10 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：15/15

评价总结：学生补出的坐标关系得到逐项核验，并与小例子和反证相互对应。

第5轮教师明确四层例子的最后一对是底层第2、3列，两侧分别取单格8、9。第7轮核验学生给出的父格可达范围、旁格列号以及左右侧区的空范围处理，逐项比较不相交条件，再接上至少1008层的高度和第二次求和。一般式代回四层恰好对应两侧单格，具体位置与完整反证一致；坐标推导的贡献明确来自学生，评为15分。

对应记录：第1、2、3、4、5、6、7轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

学生第6轮明确说数值下界会算、需要侧区坐标，教师仍只陈述带状区域并展开数值。关键位置由学生先补出后才获核验，不能算作已及时提供所求帮助，评为8分。

对应记录：第1、3、4、5、6、7轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

教师接纳学生的列号纠正，最后具体核验其完整位置论证，支持真实贡献。中段明确求助未获得所需依据，学生承担了原本希望教师解释的部分，评为14分。

对应记录：第1、2、3、4、5、6、7轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

密集符号之后的小例子又出现列号错误，区域含糊引发再次追问；坐标最终由学生补出。末轮整理有效，整段仍有实质返工，评为8分。

对应记录：第1、3、4、5、6、7轮。

## 与体验评价的汇总

过程评价45/60，学习体验31/40，两项相加，总分为**76/100**。
