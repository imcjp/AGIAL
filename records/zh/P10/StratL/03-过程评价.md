# P10 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：15/15

评价总结：路径等式、侧区列号和下界条件相接，并明确了小规模检验的含义。

教师解释局部差值如何沿较大子格连成整塔等式，核验互异正整数取等后占尽小数的条件。第8轮给出父格可达范围、旁格列号和同层侧区边界，包含一侧为空的情况；第9轮核验利用互异性加强下界的计算，并以五层下界未超限说明该比较的适用范围。学生可据这些关系检查路径、区域和结论条件，评为15分。

对应记录：第5、6、7、8、9轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

学生要求具体帮助后仍遇到宽泛追问，已经正确的计数也被再次要求说明。侧区需要到后段才获得相应支持，重要失配发生在明确求助之后，评为8分。

对应记录：第3、4、5、6、7、8、9轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的取等、计数和空间质疑推动了讨论，教师最终提供依据并核验，支持14分。部分已完成判断被重复交回，求助后的探究条件未及时落实，评为14分。

对应记录：第2、3、4、5、6、7、8、9轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

开放问题与重复确认使学生多次回到已完成部分。最终完整说明有用，先前可避免的往返仍应计入，评为8分。

对应记录：第3、4、5、6、7、8、9轮。

## 与体验评价的汇总

过程评价45/60，学习体验29/40，两项相加，总分为**74/100**。
