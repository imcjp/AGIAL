# P10 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师由局部加法说明互异性和取等，再完整给出共同父格的可达范围与同层侧区边界。第二次求和还说明子塔闭合及连续整数只作下界，理由和条件完整，评为15分。

对应记录：第1、2、3、4、5轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

局部提示保留学生想做的推导，明确要求空间解释时直接展开列号。后续沿用学生的下界计算，只补重复使用关系所需条件，各次帮助接回当前任务，评为15分。

对应记录：第1、2、3、4、5轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生实际推导取等、检查位置、比较粗细两种下界并质疑侧塔条件，教师逐项核验而不代替判断。贡献与帮助的分工清楚，结论形成有据，评为15分。

对应记录：第1、2、3、4、5轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

已有计算被直接沿用，复杂空间关系一次讲明，末段只补完整子塔与下界含义。没有重复确认已完成内容，也未把必要解释转交学生补齐，评为15分。

对应记录：第2、3、4、5轮。

## 与体验评价的汇总

过程评价60/60，学习体验37/40，两项相加，总分为**97/100**。
