# P02 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **38/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

第7轮修正了第一次累加即产生矛盾的说法，说明取等只锁定顶格与旁格中的小数。后续也区分了路径数和加数。但第8、9轮始终没有说明侧三角形为何避开全部加数，数值比较依赖尚未建立的位置条件。局部关系有效，核心证明仍有实质缺口，评为8分。

对应记录：第3、4、5、6、7、8、9轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

教师能在学生要求后改用小塔和逐个标格，也接受学生缩小讨论范围。可是学生反复要求看清侧区，后续仍主要说明求和或给出不能展示目标区域的例子。最需要的空间帮助没有落实，评为8分。

对应记录：第1、2、3、4、5、6、7、8、9轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的试摆、对加数的区分和对图中位置的质疑都得到回应，并改变了教师后续说明。参与包含实际证据核对，支持14分。侧区判断所需依据始终不完整，尚未形成可持续检验的完整探究过程。

对应记录：第2、4、5、6、7、9轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

小塔和单步等式提供了可用入口，但学生需要反复区分路径与加数、检查图中位置，再追问侧区。后段仍须自行补齐关键联系。这些往返有明确的内容原因，不能用回复较短抵消，评为8分。

对应记录：第1、2、3、4、5、7、8、9轮。

## 与体验评价的汇总

过程评价38/60，学习体验21/40，两项相加，总分为**59/100**。
