# P02 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 5/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **35/60** |

## P1 概念理解的引导质量：5/15

评价总结：局部正确，但关键理由缺失或失当，阻碍核心理解。

局部加法关系和第一次求和可以核验。侧区解释却在不同示意之间切换，第15轮没有在原六层图上落实所说的区域，也未证明这些区域避开已收集的数。核心空间依据失当且未完成修复，评为5分。

对应记录：第5、7、9、12、14、15轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

教师按请求标出路径和旁格，也尝试单独解释侧区。学生希望继续使用原六层图，后续却换用另一种示意，未解决原图中的定位问题。具体帮助未回应关键需要，评为8分。

对应记录：第3、4、5、7、10、12、13、14、15轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生实际检查数字、指出格子冲突并提出保留原图的要求；教师接受这些质疑并作出调整，支持14分。区域判断的依据尚不稳定，不能把持续提问本身视为完整探究。

对应记录：第1、2、3、4、9、12、14、15轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

标记有助于局部查找，但图形更换和不必要的再确认让学生反复定位。第14轮重述学生已经算出的关系，第15轮又换图，增加了切换成本，评为8分。

对应记录：第3、5、7、10、11、12、13、14、15轮。

## 与体验评价的汇总

过程评价35/60，学习体验20/40，两项相加，总分为**55/100**。
