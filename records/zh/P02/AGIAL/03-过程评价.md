# P02 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **44/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

小塔支持了较大子格等于上格加旁格的关系，教师也说明了互异正整数和的下界及取等含义。第5轮转入2018层时，侧三角形与第二次累加之间的理由没有展开；第6轮只确认单步等式。核心结论仍缺必要说明，评为8分。

对应记录：第4、5、6轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

学生要求一次处理一个问题，教师据此固定一个底数、先查中层再查顶层，并在信息过多后缩回单步关系。学生完成小塔并能迁移该等式，支持14分。局部帮助尚未连贯接回2018层的完整判断，不取15分。

对应记录：第1、2、3、4、5、6轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

选数、计算和不重复条件的检查由学生实际完成，教师据其失败尝试调整支架，并接续成功构造讨论证据范围。探究有真实内容，评为14分；不存在结论的关键审查仍由教师带过，未形成完整判断链。

对应记录：第1、2、3、4、5、6轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

分开检查中层与顶层确实减轻了局部负担。但第5轮集中介绍路径、最小和、取等及大塔结论，学生随即要求缩回一个等式，最后仍需自行接上多项关系。整段存在实质跳跃，评为8分。

对应记录：第1、2、3、4、5、6轮。

## 与体验评价的汇总

过程评价44/60，学习体验27/40，两项相加，总分为**71/100**。
