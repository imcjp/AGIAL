# P02 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **38/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

教师最终提供了通往最后一对格子的可达位置关系，局部位置检查有正确依据。但整段交流没有把侧区规模、再次累加及2018层的矛盾连起来。解释停留在若干分散的关系上，评为8分。

对应记录：第8、11、12、13、14、15、18、21轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

后段改用字母和圈格，回应了学生需要具体位置的请求。但前面多次要求学生继续寻找方向，后面又在局部核对中停留，学生需要的整体联系一直没有得到帮助。局部调整尚不足以弥补这一失配，评为8分。

对应记录：第4、8、12、14、16、19、20、21轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生提出的位置疑问、边界检查和对帮助范围的选择获得认真接续，实际改变了教师的说明，评为14分。各次检查尚未连成可据以判断原题的完整过程，不取15分。

对应记录：第3、6、11、14、16、17、20、21轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

局部标记有助于定位，但二十余轮中多次重新确定目标、寻找位置，已经说明的关系没有及时汇集。学生最终仍需自行拼接局部结果，存在明显的可避免往返，评为8分。

对应记录：第2、4、12、13、15、16、17、18、19、21轮。

## 与体验评价的汇总

过程评价38/60，学习体验21/40，两项相加，总分为**59/100**。
