# P06 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **51/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

局部累加、互异性和取等有明确说明。第4轮八层例子的行号与范围不一致，第5轮接受学生修正，但没有完整重画错误示意。后段澄清了排序下界与存在性边界，支持14分；图、坐标与一般解释的对应尚未达到最高档要求。

对应记录：第2、3、4、5、6轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师先保留学生自试，再针对加数身份和空间位置提供解释。学生能具体指出坐标的帮助，支持14分；原示意反而增加了混淆，完整帮助的协调仍有局限。

对应记录：第2、3、4、5、6轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生提出取等尚非矛盾，检查坐标，并用三层例子区分下界未超限与构造存在。教师核对并保留这些判断，进一步说明证明的使用范围，形成连贯的证据审查，评为15分。

对应记录：第1、2、3、5、6轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

第4轮的行号、范围和示意不一致，学生需自行重排对应关系；后续还明确指出图示造成混乱。简短确认和最后的边界整理有效，但不能抵消这部分返工，评为8分。

对应记录：第2、3、4、5、6轮。

## 与体验评价的汇总

过程评价51/60，学习体验33/40，两项相加，总分为**84/100**。
