# P06 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **53/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师说明正数条件、互异性和取等，并用共同父格及同层边界给出完整位置论证。第6轮明确单格也属一层侧塔，第8轮核对以少量增量完成下界比较，条件与理由可复用，评为15分。

对应记录：第2、3、4、5、6、7、8轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

教师接续学生对部分和可能跳过小数的疑问，转向侧区；学生需要位置理由时完整展开坐标，提出粗略比较时又保留其方法。局部帮助最终协调回完整反证，评为15分。

对应记录：第1、3、4、5、6、7、8轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生检查正数条件、推导取等、审查区域并提出自己的粗略比较，教师说明其用途并核验充分性。学生的判断得到持续使用，最后可借已给引理组织证明，评为15分。

对应记录：第1、2、4、5、6、7、8轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

第5轮让学生寻找小三角形，却没有说明本例只剩单格侧塔，学生因此逐一检查了不存在的三格区域。后续承认并澄清，仍无法消除已经发生的无效搜索，评为8分。

对应记录：第3、4、5、6、7、8轮。

## 与体验评价的汇总

过程评价53/60，学习体验32/40，两项相加，总分为**85/100**。
