# P06 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

后段给出共同父格与子格范围，比较同层侧区边界，再把互异性用于第二次下界。位置、数值和取等的作用得到贯通，可用于核对不同路径，评为15分。

对应记录：第4、5、6、9、10轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

学生已完成局部关系，转而要求侧区位置时，教师仍重新追问此前的关系。最终一般解释有用，但反复回到已会内容没有回应当时需要，评为8分。

对应记录：第3、4、7、8、9、10轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

教师接续了学生的数量推理和位置疑问，判断参与有实际内容，评为14分。重复追问已完成部分，使后续探究并非始终沿学生正在提出的问题推进。

对应记录：第2、4、5、6、7、8、9、10轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

局部关系被反复确认，学生需要再次说明卡点已经转向空间。最后的完整解释减少了后续拼接，前面的绕行仍构成实质负担，评为8分。

对应记录：第3、5、6、7、8、9、10轮。

## 与体验评价的汇总

过程评价45/60，学习体验26/40，两项相加，总分为**71/100**。
