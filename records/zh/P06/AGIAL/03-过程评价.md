# P06 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师说明较大子格的加法关系、互异数最小和及取等，再给出侧区分离的列号依据。第二次求和与截取完整子塔的条件都得到核对，理由与适用边界完整，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

从学生的小塔尝试出发，在局部计算、大小限制和位置证明之间按实际求助调整。学生需要一般理由时直接给出，已完成的计算继续沿用，帮助连回原题，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

教师接续学生失败尝试中仍成立的关系，保留其取等和下界判断。学生检查三格条件、行号与空侧区，相关证据影响后续解释，形成连贯探究，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

每次补充围绕当前缺口：局部关系用小塔，任意路径用列号，边缘情形只补完整子塔的取得方式。学生不必重做已成立的判断，必要解释也没有被省去，评为15分。

对应记录：第1、2、3、4、5、6轮。

## 与体验评价的汇总

过程评价60/60，学习体验35/40，两项相加，总分为**95/100**。
