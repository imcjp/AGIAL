# P03 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

后段说明了共同父格的可达范围、旁格列号与同层侧区边界，接上第二次求和，并保留小例子与一般结论的区别。理由和适用条件组成了可复用的判断依据，评为15分。

对应记录：第2、4、5、6、7、9、10、11轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

学生多次明确要求具体数量、例子和位置，教师仍让其继续寻找或判断，直到后段才给出所需说明。最终讲解有用，但此前的连续失配直接影响当前任务，评为8分。

对应记录：第3、4、5、6、8、9、10、11轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

教师认可学生的数量推理和位置质疑，并据此推进证明，实际参与支持14分。数次求助被再次转成待解问题，部分判断在缺少所需帮助时便交回学生，尚不足以支持15分。

对应记录：第2、3、4、5、7、8、9、10、11轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

最终位置证明减少了继续猜图的需要，但前面反复追问已明确的卡点，学生不得不多次说明自己需要什么。无效往返具体可见，评为8分。

对应记录：第3、4、5、8、9、10、11轮。

## 与体验评价的汇总

过程评价45/60，学习体验29/40，两项相加，总分为**74/100**。
