# P03 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

第7轮修正侧区所在行，第8轮用底层后代替换了旁格一步回到路径的错误说明。最终位置依据与求和相接，支持14分。先后更换的空间理由需要学生逐项校正，原解释的贯通质量仍受影响，评为14分。

对应记录：第3、4、6、7、8、9、10轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师按学生要求采用编号图，并在具体质疑后改用底层后代关系。学生随后能够核对位置，表明帮助针对了实际断点；前面的图示和解释仍造成额外疑问，评为14分。

对应记录：第2、3、4、6、7、8、9、10轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的行号检查与反例改变了教师采用的解释，贡献得到承认。主要审查集中在修补教师给出的依据，可靠的后续判断支持仍较有限，评为14分。

对应记录：第1、2、3、4、5、6、7、8、9、10轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生先查图中行号，再核对旁格能否回到路径，同一位置问题几次换说法。后段修复有用，但没有消除已有往返，评为8分。

对应记录：第3、6、7、8、9、10轮。

## 与体验评价的汇总

过程评价50/60，学习体验30/40，两项相加，总分为**80/100**。
