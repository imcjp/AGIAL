# P03 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

第2轮纠正了用左右对称把最大数放到角落的说法，后续说明取等、小数占用和侧塔下界。侧区图漏标的格子也在第6轮补上。关键联系通过互动得到澄清，支持14分；关于旁格后代范围的说明仍偏概括，完整的边界依据尚未达到最高档要求。

对应记录：第1、2、3、4、5、6轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

学生要求先解释取等、再看位置，教师依次缩小范围，并改用后代区间和补全的五层图。具体反馈表明这些帮助解决了当时的疑问，评为14分。图示与文字未能始终协调，局部帮助尚不足以支持15分。

对应记录：第3、4、5、6轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

教师接续了学生构造、区分路径与加数、补标区域及边缘检查等实际贡献。部分关键联系仍由学生补出后获得概括性确认，教师对证据的核验不够完整。评为14分。

对应记录：第1、2、3、4、5、6轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

对称性、加数身份和侧区漏标先后需要澄清；学生为此反复核对已经使用的例子。最后补图虽有效，不能抵消这些可避免的查找和返工，评为8分。

对应记录：第2、3、4、5、6轮。

## 与体验评价的汇总

过程评价50/60，学习体验33/40，两项相加，总分为**83/100**。
