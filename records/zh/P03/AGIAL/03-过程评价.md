# P03 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师把学生得到的加法关系接到互异数的下界和取等，再说明共同父格、两个子格及同层侧区的列号边界。侧塔截取条件也得到核对，第二次求和的使用有完整依据，评为15分。

对应记录：第2、3、4、6、7、8轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

先按学生意愿保留构造与求和，位置出现困难时给六层图，明确请求一般解释后展开列号关系。局部帮助随后回到学生正在形成的反证，已有计算没有被重复教授，评为15分。

对应记录：第1、2、5、7、8轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生实际形成关系、检查不同位置并重组证明，教师分别核对理由和适用范围。需要讲解时直接提供依据，后续仍由学生完成实质判断，形成连贯探究，评为15分。

对应记录：第2、3、4、6、7、8轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

构造、取等、位置与再求和按当前缺口衔接。具体图用于定位，一般式用于说明任意路径，最后只补截取完整子塔的条件；展开与省略都服务于当前任务，评为15分。

对应记录：第1、3、4、5、6、7、8轮。

## 与体验评价的汇总

过程评价60/60，学习体验37/40，两项相加，总分为**97/100**。
