# P05 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **38/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

教师提供了路径求和和取等的有效起点，但第10、11轮仍以路径能够到达最后一对解释旁格必然在侧区外，没有补出两者之间的必要联系。一般位置理由尚不完整，评为8分。

对应记录：第7、9、10、11轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

学生已经会用差值关系，多次要求具体对象和一般理由，教师仍让其寻找关系或继续判断。后段说明未解决明确提出的空间疑问，评为8分。

对应记录：第3、6、7、9、10、11轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生实际提出和式、取等与侧区的疑问，教师接纳并据此推进，支持14分。旁格排除的依据没有补全，尚不能把这些局部参与记为完整连贯的探究，评为14分。

对应记录：第2、4、5、6、7、9、10、11轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

已完成的局部关系被再次追问，一般位置的缺口也需学生反复提出。虽然求和阶段可以继续，证明仍需自行补接，评为8分。

对应记录：第3、4、5、6、8、9、10、11轮。

## 与体验评价的汇总

过程评价38/60，学习体验28/40，两项相加，总分为**66/100**。
