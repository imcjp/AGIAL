# P05 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师从局部加法接到排序下界和取等，说明共同父格与旁格的列号范围，再与侧区边界比较。步数、完整子塔以及未排除不等于存在均得到解释，形成有边界的判断依据，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

学生想先看区域而保留大小推导，教师提供位置图并说明它的适用范围；一般理由需要展开时直接讲清，后续再由学生完成数值比较。帮助与学生希望承担的工作衔接，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生实际构造、推导下界并核对步数及边缘情况，教师沿用这些贡献，说明哪些结论已有依据、哪些仍待证明。讲解与自主判断的分工清楚，评为15分。

对应记录：第1、2、3、4、5、6轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

具体图只处理位置，一般式解释任意路径，计算沿用学生已有结果。后段仅补步数与结论边界，没有重复整段证明，复杂处展开、明确处收束，评为15分。

对应记录：第1、2、3、4、5、6轮。

## 与体验评价的汇总

过程评价60/60，学习体验35/40，两项相加，总分为**95/100**。
