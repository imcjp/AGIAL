# P05 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

初始小塔和后代范围先后出现问题，教师在第2、6轮修正，后续说明了侧区与求和的联系。互动澄清了关键断点，评为14分；示例、位置依据和一般结论未能始终保持一致，最高档依据仍不充分。

对应记录：第1、2、3、4、5、6轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师根据学生实际质疑更换例子、修正后代范围，具体帮助能处理眼前问题。但两处关键表示需要学生先指出冲突，局部帮助与完整任务的衔接不够稳定，评为14分。

对应记录：第1、2、3、4、5、6轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的构造、范围检查和反例得到接续，并改变了后续讲解。教师支持了实际判断，但若干邀请建立在尚需修正的材料上，证据审查的连续性有限，评为14分。

对应记录：第2、3、4、5、6轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生需要先核验例子，再追查后代范围，同一证明在不同表示间反复修补。后段可用的解释没有消除这些额外工作，评为8分。

对应记录：第1、2、4、5、6轮。

## 与体验评价的汇总

过程评价50/60，学习体验31/40，两项相加，总分为**81/100**。
