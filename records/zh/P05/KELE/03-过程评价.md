# P05 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **51/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

第6轮用第五层后代排除旁格的理由不充分，第7轮承认并改为底层后代，后续接上第二次求和及去掉数值上限的边界。主要概念已贯通，但两个子格为何都碰到最后一对仍较概括，评为14分。

对应记录：第3、4、5、6、7、8轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师按学生要求提供六层编号图，并根据反例改变空间解释，学生后续能据此计算和检查条件。局部帮助有具体反馈支持，但前面零散改写和位置解释尚未形成顺畅衔接，评为14分。

对应记录：第1、3、6、7、8轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生用反例修改位置判据，又独立比较第二次下界并提出取消数值上限的变式。教师明确采纳这些贡献，核对变式中哪些理由失效，并限定可得结论，探究连贯，评为15分。

对应记录：第1、2、3、4、5、6、7、8轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生先询问单步改写的用途，之后又需反驳第五层后代的排除理由。编号图和修正后的说明有用，但这些可避免的回查构成实质负担，评为8分。

对应记录：第3、4、5、6、7、8轮。

## 与体验评价的汇总

过程评价51/60，学习体验33/40，两项相加，总分为**84/100**。
