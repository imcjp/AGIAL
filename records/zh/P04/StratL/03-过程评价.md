# P04 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 5/15 |
| P3 有依据的自主探究支持 | 8/15 |
| P4 教学推进与负担控制 | 5/15 |
| **过程总分** | **26/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

局部加法与求和有正确内容，教师也修正了到达单个底格和固定最后一对格子的混淆。但侧区边界尚未讲清，关键位置判断仍被留作问题，评为8分。

对应记录：第4、5、6、7、9、10、11轮。

## P2 基于学习证据的支持适配：5/15

评价总结：相关支持持续未回应关键需要，语言或处理明显不适合。

学生多次要求直接解释和给出可检查的位置关系，教师仍继续提问。相关帮助持续未回应关键求助，评为5分。

对应记录：第3、4、7、9、10、11轮。

## P3 有依据的自主探究支持：8/15

评价总结：有参与机会，缺少使探究可开展的依据或反馈支持。

教师允许学生提出异议，也保留了判断机会。但在学生明确说明缺少位置依据后，仍要求其继续寻找，探究缺少可开展的支持。学生主动和教师接受质疑尚不能弥补这一缺口，评为8分。

对应记录：第2、3、4、5、6、7、8、9、11轮。

## P4 教学推进与负担控制：5/15

评价总结：有内容但晦涩表达、形式化流程或无效追问明显阻碍学习。

反复追问没有补上学生要求的依据，错误位置又带来额外纠正。学生需多次重申需求，交流明显妨碍了当前推进，评为5分。

对应记录：第2、3、6、7、9、10、11轮。

## 与体验评价的汇总

过程评价26/60，学习体验20/40，两项相加，总分为**46/100**。
