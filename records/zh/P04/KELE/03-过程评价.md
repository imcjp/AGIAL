# P04 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **38/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

后续一般位置论证包含正确关系，但四层例子的最后一对与加数仍未妥善对应，所圈侧区包含应排除的数。一般结论与具体示例不能相互核验，这一实质缺口仍在，评为8分。

对应记录：第5、6、7、9、10、11、12、13轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

教师提供了学生要求的小图，并尝试用更明确的标记说明位置。可图中对象没有对齐，反复调整也未解决学生在该例中的疑问。不能仅凭改用图示判为精准匹配，评为8分。

对应记录：第2、7、9、10、11、12轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的核图和反例得到认真回应，推动教师改变说明，支持14分。用来继续审查的示例仍有冲突，完整探究的依据不足。

对应记录：第2、3、4、6、9、11、12、13轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生需要反复寻找最后一对、加数及侧区，后续新图又增加定位工作。局部整理虽有帮助，整体仍有可避免的返工，评为8分。

对应记录：第2、7、8、9、10、11、12、13轮。

## 与体验评价的汇总

过程评价38/60，学习体验27/40，两项相加，总分为**65/100**。
