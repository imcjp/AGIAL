# P01 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 5/15 |
| **过程总分** | **35/60** |

## P1 概念理解的引导质量：8/15

评价总结：主要解释有效，但有影响当前理解的实质缺口。

教师借学生的小塔把差改写成加法，说明逐层累加时加数互异，利用正整数最小和与全塔上限推出取等，并解释小数已被这些加数占尽。若存在所需侧塔，第二次累加超过全塔最大数的计算也正确。

两层图曾漏格，相邻关系及排除解释也有错误，后来通过共享下格的关系修正了局部例子。末次说明将数值矛盾限定在侧塔确实存在的条件下，但任意路径都能留下足够大、且避开全部加数的完整侧塔，仍缺少证明。主要代数关系有效，必要的空间理由尚未补齐，因此评为8分。

对应记录：第6、7、9、10、11、14、15、16轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

教师后来能按具体疑问改成一次一步，沿用学生已有摆法解释最小和、差转加法及逐层累加，并允许用文字推广。位置分类和末次按要求集中计算也回应了具体请求，学生据此继续完成了多段推理。

前段学生多次要求具体提示，却仍被要求自选问题或泛想限制，所需帮助迟迟未给出。后段学生需要可核对的空间说明，得到的却是错误图解和密集修订，随后要求不再加图。有效的局部调整未能充分回应整个交流中的关键需要，因此评为8分。

对应记录：第3、4、5、6、7、8、10、12、14、15、16轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生参与了试摆、判重、推广路径和及审查取等条件。关于左右走法、共享下格和一般性保证的质疑，促使教师撤回错误、修正局部图，并把最后的结论限定为侧塔存在时才成立的矛盾。学生提出的证据确实改变了教师的主张。

前段学生求助后，教师仍多次把方向选择交回，却未及时提供可供判断的依据；后段的证据审查又数次停在错误图示的修补上。已有实质判断和相应修订，但前后探究没有连贯接续，末次限定结论也不能补足这些中断，因此评为14分。

对应记录：第1、2、4、7、8、9、10、11、13、14、15、16轮。

## P4 教学推进与负担控制：5/15

评价总结：有内容但晦涩表达、形式化流程或无效追问明显阻碍学习。

中段的一步加法、原例复用和分层记录较易跟随；走、记、剩的标记帮助定位，末次单独展开数值计算也便于核对。这些安排减少了部分查找和抽象转换。

前段反复要求已卡住的学生自行找方向，后段第14轮给出漏格图和较长的错误解释，第15轮又在同一回复中改图、改最后一对并重新排列。学生需要来回检查，随后明确要求不再添图。问题已超出一般重复，直接妨碍了必要空间说明的使用，因此评为5分。

对应记录：第3、5、6、7、12、14、15、16轮。

## 与体验评价的汇总

过程评价35/60，学习体验23/40，两项相加，总分为**58/100**。
