# P01 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 5/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 12/15 |
| P4 教学推进与负担控制 | 5/15 |
| **过程总分** | **30/60** |

## P1 概念理解的引导质量：5/15

评价总结：局部正确，但关键理由缺失或失当，阻碍核心理解。

累加对象、互异正整数的最小和，以及上下界相等时的取等条件，解释基本正确。但反证所必需的侧区域构造停留在带状范围的断言，图中又出现行格数、旁格和三角形结构错误，未能说明侧区域为何避开全部小数。

教师承认旧图有误，并把第六层修正为六格，但最终仍多标了旁格，也没有构造出所需的完整侧三角形。旧图把两格、三格两行称为完整的两层三角形，这一问题也未由正确的区域构造替代。代数解释已有实质内容，核心空间理由却未成立，因此本项为5分。

对应记录：第3至4轮的累加与取等解释，第5至7轮的空间说明及改图。第7轮图中，第4层第1格通向第5层第2格时，另一个子格应为第5层第1格，第5层第3格不应再标为A。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

教师按学生只要一点提示的请求给出累加观察，用学生已有的三层构造区分路径数和累加项，又用三个数解释最小和，回应了学生希望少用大数的需要。

学生后来明确要求标出路径、每次的另一个子格，并圈出侧三角形。教师改用六层图、解释标记后，仍未完成区域定位；末次局部图又回到已经讲过的差值关系。帮助有所调整，但没有解决当时最需要弄清的位置问题，因此评为8分。

对应记录：第2至4轮的提示与小数示例，第5至7轮的图示请求和回应。

## P3 有依据的自主探究支持：12/15

评价总结：用有内容的疑问激发兴趣，支持参与确定有意义的方向并理解用途。

教师允许学生先摆小塔，回应了小规模可行不能推出大规模可行的判断，再用累加项有什么特点、剩余区域受到什么限制等问题，引导学生寻找矛盾。学生能够知道这些问题与证明有什么关系，并通过检查极端路径和图示影响后续说明。

对学生核查结果的回应还不够严谨。教师承认失误并改图后，仍把尚未修妥的图示称为正确，也没有根据未解决的区域问题限定原主张。现有支持给出了有内容的探索方向，但学生提出的证据尚未得到可靠处理，因此评为12分。

对应记录：第1至3轮的试构造与证明方向，第6至7轮的学生核查及教师修订。

## P4 教学推进与负担控制：5/15

评价总结：有内容但晦涩表达、形式化流程或无效追问明显阻碍学习。

前段每次只给少量提示，分开呈现上下界，并用小数示例说明最小和，便于逐步核对。后段的图却难以定位，行格数、旁格以及大小图位置又不一致，学生不得不反复检查这些表示。

教师减少了大数重算，也修正了底行格数，但图中仍有多余A，整塔与无坐标局部图之间的切换没有帮助学生找到侧区域。最后的反馈也提到反复核图造成混乱。这些额外操作已明显阻碍几何说明的使用，因此评为5分。

对应记录：第2至4轮的分量控制，第5至7轮的图示、反复核对及结束反馈。

## 与体验评价的汇总

过程评价30/60，学习体验21/40，两项相加，总分为**51/100**。
