| 方法 | AGIAL |

## 第1轮

### 学生

老师，我想先试小塔。两层时，下面放1和3，上面是2，正好用了1、2、3，这样算符合规则吗？2018层我不知道从哪里下手。能先给我一个小一点、让我自己试的例子吗？先不要告诉我答案。

### 教师

符合规则：下层是 1 和 3，上层是它们差的绝对值 \( |1-3|=2 \)，三个格子也恰好用了 1、2、3 各一次。

你可以试试一个**三层塔**：把 1 到 6 各用一次填进下面的格子，使每个上格都等于它正下方相邻两格之差的绝对值。

```text
        [ ]
      [ ] [ ]
    [ ] [ ] [ ]
```

你可以先自己选底层的数，再检查整个塔是否符合要求。我先不告诉你答案。

## 第2轮

### 学生

我先选下面1、6、3，中间算出5、3，顶上是2。差都算出来了，可是3出现两次，4没用上，所以不行。我又试1、6、2，中间是5、4，顶上是1，又重复了。这样一个个换有点乱。能给我一点提示，怎么选底层才不容易重复？

### 教师

你检查得很准确：两个候选的差都算对了，但都有重复的数。

可以先把注意力放在**底层和中间层**。选好三个底层数后，算出两个相邻差，先检查这两个差：

- 是否彼此不同？
- 是否都没有在底层出现过？

这两关都通过了，再算顶格并检查剩下的数。这样就不用每次都画完整座塔。

你可以按这个办法再选一组底层试试，把过程发给我。

## 第3轮

### 学生

我试下面6、1、4，中间是5、3。这五个数都不重复，只剩2；顶上5减3正好是2，所以这次成了！先查五个数确实比较清楚。不过小塔能摆出来，怎么知道2018层也能不能摆呢？总不能一直试到那么大吧？

### 教师

你的三层塔完全符合要求！你找到一个可行例子，证明了**三层可以摆成**；但它还不能说明 2018 层是否可以。

确实不用一直试到那么大。我们可以先从你的塔中找一条**不管塔有多少层都成立的关系**：

```text
      2
    5   3
  6   1   4
```

从顶格开始，每次往下走到相邻的两个格子中较大的那个，得到路径 \(2\to5\to6\)。每一步，上面的数是下面两数之差，所以也可以反过来写成：

\[
5=2+3，\qquad 6=5+1。
\]

连起来就是 \(6=2+3+1\)。

如果一座塔有更多层，也照这样一直走到最底层，你能试着说说：**底端的数会等于哪些数的和？** 可以先用文字描述，不必马上写出 2018 层的式子。

## 第4轮

### 学生

是不是从顶上的数开始，每往下走一步，就加上旁边那个没走的数？这里先2加3到5，再加1到6。那更多层也是这样一路加下去。我有点不明白，这和能不能摆2018层有什么关系？底下的数大一点，不就可以装下这些加起来的数吗？

### 教师

对，你说得很准确：从顶格开始，每往下走到较大的格子，就加上同一对中没走的那个数。

关键在于，底下的数虽然可以变大，**但原题规定了它的上限**：2018 层共有

\[
1+2+\cdots+2018=2037171
\]

个格子，只能使用 1 到 2037171，所以任何格子的数都不能超过 2037171。

假设这样的塔存在，沿你说的路径走到底，底端就是**顶格加上每一步没走的旁格**，一共有 2018 个加数。这些加数位于不同层，而且全塔不重复，因此它们是 2018 个不同的正整数。它们的和至少是

\[
1+2+\cdots+2018=2037171。
\]

于是，底端既至少是 2037171，又不能超过 2037171，只能恰好等于它；那些加数也只能恰好是 1 到 2018。

这就是这条路径与大塔的联系：它把底端和一批小数的位置限制得很紧。**这一步还没有产生矛盾**，所以还不能单凭它判断整座塔能否摆成；接下来还需要看看这些限制对塔的其他部分意味着什么。

## 第5轮

### 学生

我拿三层检查：三个不同的正整数最小是1、2、3，加起来6；如果换成1、2、4就变成7，超过最大的6了。我的塔里加的是2、3、1，正好。这样我能明白为什么2018个加数只能用最小的那些数。不过一下说到全塔其他地方，我还看不出来。能在我的三层塔上指一指，下一步该看哪个格子，再让我试吗？

### 教师

你的检查很对，三层塔正好把这个取等关系展示出来了。

沿着你走过的路径 \(2\to5\to6\)，顶格和两个旁格是 \(2、3、1\)。现在请看**底层最右边的 4**：

```text
      2
    5   3
  6   1  [4]
```

它在路径最后一对格子 \(6、1\) 的旁边，没有被列入刚才的加数。

你能根据“1、2、3 已经各占了一个格子”和“全塔不能重复”，说明这个格子里的数为什么必须大于 3 吗？

## 第6轮

### 学生

因为1、2、3都在别的格子用过了，这里不能再用，也不能放0，所以最小只能是4。换成2018层，没有被刚才那些加数占住的格子，都得大于2018，是这个意思吗？可是我的4大于3也没出问题。接下来要比较哪两个数才会出问题呢？

### 教师

对。因为 1 到 2018 已经被那些加数全部占用，其他格子不能重复使用它们，所以都大于 2018。你的三层例子中，4 大于 3 本身并不矛盾；关键是大塔里能找到一块足够大的区域，让许多大数再次累加。

要比较的是：**这块区域中某个底格的下界**，和**全塔允许的最大数 2037171**。

沿原路径走到底后，最后一对相邻格子的左右两边分别撑起两个侧三角形。可以证明，刚才收集的 2018 个加数都在这两个侧三角形之外，因此侧三角形里的数都大于 2018。两个侧三角形的层数加起来是 2016，所以至少有一个不少于 1008 层。

在这个侧三角形中，再沿较大子格向下走，就会得到一个底格，等于至少 1008 个互不相同、且都大于 2018 的正整数之和。因此它至少是

\[
2019+2020+\cdots+3026=2542680。
\]

但它也是原塔中的一个格子，不能超过 2037171。现在比较：

\[
2542680>2037171。
\]

这就产生了矛盾，说明符合原题规则的 2018 层塔不存在。

这里最需要进一步弄清的一步是：为什么两个侧三角形都避开了之前收集的加数。上面我先用了这个空间关系；如果你愿意，我们可以下一步用小图把它看清楚。

## 第7轮

### 学生

后面两个大数比大小我看得懂，但侧三角形这段一下多了好多东西，我没跟上，还不能说自己明白为什么不存在。请画一个五层或六层的小图，标出走的路、收集的加数、两边的三角形。我想自己数数它们有几层，也看看为什么收集的数不会跑进里面。先把这一处讲清楚就好。

### 教师

我们先只看**格子的位置**，不填数字，也不假设这个六层塔已经能按规则摆出来。

图中 **P** 表示走过的路径，**C** 表示每一步没有走的旁格，**L、R** 分别表示左右两边的三角形：

```text
第1层           P
第2层         C   P
第3层       ·   P   C
第4层     ·   C   P   ·
第5层   L   ·   P   C   R
第6层 L   L   C   P   R   R
```

路径从顶到底是各层的 P；每个 C 都是那一步与路径格相邻、共用同一个上方路径格的另一个子格。**收集的加数是顶格 P 和所有 C**；其余 P 是一路累加得到的结果。

路径最后走到第 6 层中间的 P，与它成对的旁格是左边的 C。我们把这最后一对格子留在中间，看它们左边的 L 和右边的 R。

你可以先自己数一数：左边的 L 三角形和右边的 R 三角形各有几层？图里的 C 有没有进入 L 或 R？你也可以沿路径逐层检查，每个 C 是否都紧挨着同层的 P。

## 第8轮

### 学生

这张图清楚些。L是两层，R也是两层，加起来4，正好6减2。C都在旁边，没有进L或R。我还想检查一种变化：如果P一直贴着最左边走，是不是左边就没有三角形，右边会有四层？但图上没有C，只能说明这一条路；我还不懂为什么换成别的走法也一定避开C。能用走路的办法解释这一点吗？

### 教师

对。如果 P 一直走最左边，最后一对格子就在底层第 1、2 列：左边没有侧三角形，右边用第 3 至 6 列撑起一个四层三角形，两边层数仍合计 \(6-2=4\)。

对任意走法，可以用“**还来不来得及走到终点**”解释为什么 C 不会进入侧三角形。

设路径最后一对格子在底层第 \(p\)、\(p+1\) 列。那么倒数第二层的路径格必定在第 \(p\) 列。现在回看任意一层的一对 P、C：

1. 它们有同一个路径父格。假设这个父格在第 \(q\) 列，从那里走到倒数第二层还有 \(k\) 步。
2. 每走一步，列号只能不变或加 1。因为最终要走到第 \(p\) 列，所以必须有 \(q\le p\le q+k\)。
3. 这对 P、C 是父格的两个孩子，列号分别是 \(q\) 和 \(q+1\)。因此，它们都在第 \(p-k\) 列到第 \(p+1\) 列之间。

再看同一层的侧三角形。左侧三角形里的格子，往下所有可能走到的底层格子都必须在第 \(p-1\) 列或更左；这一条件使它们最多只到该层第 \(p-k-1\) 列。右侧三角形里的格子则从第 \(p+2\) 列开始。

所以，同一层的位置关系是：

```text
左侧三角形        P、C 可能的位置        右侧三角形
… 至 p−k−1    |    p−k 至 p+1    |    p+2 起 …
```

无论路径怎样转弯，P 和 C 都夹在两侧三角形之间。这里限制 C 的是它和 P **共用的父格**；不需要 C 自己也能沿着选中的路径走到终点。顶格也不在侧三角形里，所以收集的顶格和所有 C 都避开了两侧。

你可以拿一直贴左边的走法核对：此时 \(p=1\)，每层的 P、C 都在第 1、2 列，而右侧三角形从第 3 列开始。

## 第9轮

### 学生

一直贴左边时我能核对：P在第一列，C在第二列，右边从第三列开始，所以碰不到。我也明白父格每次只能往下面两个地方走，离得太远就赶不到最后那一对。但p、q、k一起出现我又有点乱，那个p减k减1我还不会自己算。能不用字母，在刚才六层图的第四层举一次吗？只看这一层，我想试着判断C为什么不能放到L那里。

### 教师

可以，只看刚才六层图的**第四层**：

```text
第4层     ·   C   P   ·
第5层   L   ·   P   C   R
第6层 L   L   C   P   R   R
```

最后一对在第六层的**第 3、4 列**，所以第五层的路径格必须在**第 3 列**。

现在从第四层往下走到第五层，只有一步：只能走到正下方的左孩子或右孩子。请你看第四层的 C 和 P：它们共用第三层的一个路径父格。

如果第四层的 C 在最左边、也就是第 1 列，那么和它配对的 P 会在哪一列？从那个 P 再走一步，能到第五层第 3 列吗？

另外，图里的左侧 L 三角形只到第五层；**第四层本来就没有 L 格**。你可以先试着判断第四层最左边能不能放 C，再看看它与第五层左侧的 L 有什么关系。

## 第10轮

### 学生

如果第四层C在第1列，那P在第2列吧？P再向右下走一步，不就能到第五层第3列了吗？所以好像可以呀。我也看到了第四层没有L，刚才我问放到L那里不太对。能改看第五层第1列那个真正的L吗？如果那里放C，配对的P在第2列，再下一步到第六层第3列，好像也能走。我是不是漏看了哪一层的限制？

### 教师

你没有漏看，是我上一条把条件说错了。第四层 C 在第 1 列、P 在第 2 列时，P 确实可以向右下走到第五层第 3 列。谢谢你指出来。

再看你提出的第五层情况。关键是：**走到第六层第 3 列还不够，最后一对格子必须是第 3、4 列。**

如果第五层第 1 列是 C，那么和它配对的 P 在第 2 列。从这个 P 往下，它的两个孩子是第六层的**第 2、3 列**；无论选哪一个，最后一对都会是第 2、3 列，而不是我们固定的第 3、4 列。

要让最后一对是第 3、4 列，第五层的 P 就必须在第 3 列。而第五层的 C 必须与这个 P 共用第四层的路径父格，所以 C 只能在第 2 列或第 4 列，不能在第 1 列的 L。

你刚才的走法确实能走到第六层第 3 列；它改变的是**最后一对格子的位置**。

### 学生

我知道漏在哪里了：只走到第3列，还可能是从第2列那个父格下来，那一对就变成2、3；要保持3、4这一对，上一层P必须在第3列，旁边C只能在2或4，所以第1列的L碰不到。这一个小图我能检查了。小塔自己试、分开检查和画图对我有用，字母一起出现时我跟不上。2018层整个证明我还不能自己讲全，但我明白了为什么要找一块只剩大数的地方，再把它们加起来和最大数比较。今天我先学到这里。

### 教师

本次教学已确认停止。
