# P01 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

教师从学生的小塔说明沿较大子格下行的累加关系，用互异正整数的最小和与全塔上限推出取等。第8轮给出共同父格及同层列号范围，说明侧三角形为何避开加数，使第二次求和有空间依据。

第9轮第四层的设问有误，第10轮纠正，并区分到达同一底格与固定最后一对底格。主要知识关系已经说明，但这一局部核验与任意路径的一般理由仍未充分接合。互动澄清了关键断点，评为14分。

对应记录：第3、4、6、8、9、10轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

学生换底数时感到混乱，教师保留其已经会做的差值计算，建议先查底层和中间层，学生随后用这一办法摆成三层塔。学生看不清侧区域时，教师沿用其小塔，再改画六层位置图；学生表示字母太多后，又缩到具体一层，最后围绕学生提出的第五层走法说明位置限制。这些调整都有明确的求助内容和随后的核对表现作为依据。

空间部分的帮助仍有几次不合适：先同时讲区域、层数和第二次求和，随后又引入多个字母，具体化时选用的第四层检查也没有解决所问问题。最后的局部说明回应了学生的新疑问，但这些帮助与整个证明之间还未接得顺畅。因此，本项认可有实际反馈支持的针对性调整，尚未达到15分要求的整体衔接。

对应记录：第1、2、3、5、6、7、8、9、10轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生实际选数、判重、推广路径和并审查取等。教师接续学生提出的走法与反例，保留正确部分，说明应固定的条件，学生的证据改变了后续解释。

第9轮错误设问一度把检查引向不能支持原判断的位置，第10轮才修正。实质参与已有依据，但部分探究需先修复教师所给任务，尚未形成贯穿完整问题的连贯支持，评为14分。

对应记录：第1、2、3、4、5、6、7、8、9、10轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

分开检查底层、中间层与顶层减少了重复计算；P、C、L、R标记也给出了查找不同格子的入口。部分局部说明有助于学生继续核对。

第6轮同时介绍空间与数值，第8轮集中引入多个字母，学生两次表示跟不上。第9轮又要求在没有L格的第四层检查，随后才改看第五层。过载、表示切换和无效检查造成实质返工，评为8分。

对应记录：第2、3、6、7、8、9、10轮。

## 与体验评价的汇总

过程评价50/60，学习体验28/40，两项相加，总分为**78/100**。
