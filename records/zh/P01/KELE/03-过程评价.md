# P01 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 12/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **48/60** |

## P1 概念理解的引导质量：12/15

评价总结：在充分解释外增加有用的概念联系或核对依据，不因多讲一步加分。

教师用局部差值关系解释路径累加，结合加数互异、最小和与全塔上限推出取等，并提供侧塔分离的一般列号论证及数值矛盾。路径格与加数格的区分、共同父格的相邻关系，也提供了具体核对办法。

第8、9轮图示先后漏标或错置格子，第10、11轮修正相邻关系和完整图示，未留下重大未纠正知识错误。但最后核对主要落在一条具体路径，一般分离理由与修正图示之间尚未通过互动贯通。现有解释及核对依据支持12分。

对应记录：第4、6、7、8、9、10、11轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师用尝试记录回应学生试摆时的混乱，用代入示范帮助其把局部加法连起来，又回到原来的小塔区分路径格与加数格。学生表示跟不上列号论证后，教师缩到两层讲相邻关系；学生再要求检查整图时，补上六层图和逐步表，并暂停已经听懂的最终加法。学生能据此核对相邻位置，说明这些调整确实对准了具体困难。

第9轮在学生需要直观图示时仍加入较长字母论证，两次错图也妨碍了所需帮助的落实。最后解决的是具体路径的核对，尚未把这部分帮助接回任意路径都成立的理由。本项14分依据是有具体反馈支持的帮助调整；局部帮助与整个理解任务的衔接还不足以支持15分。

对应记录：第2、3、4、7、8、9、10、11轮及结束反馈。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

教师保留学生试摆、判重、推广加数和审查取等的机会。学生指出图示问题后，教师接受逐层检查并重画；质疑确实改变了后续说明。

第9轮曾把来自教师示范的累加关系过度归为学生独立发现，第10轮才明确修正。最后区分了具体图核验与一般证明，学生贡献得到接续；但错图、贡献归属和结论范围数次需要纠正，完整探究的连续性仍有限，评为14分。

对应记录：第2、3、5、6、9、10、11轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

早期尝试表使学生能够沿已有记录继续试摆，减少重复计算和记忆负担。最后的六层图配合逐步位置表，将每一步的路径格和旁格对应列出，学生能按列号自行核对。

第8、9轮连续错图，使学生先后要求缩到两层、再重画全图；第9轮还在空间关系未弄清时加入长字母段和最终求和，增加了处理内容。学生随后表示跟不上，并对整图失去把握。最后的图表恢复了可核对性，但此前多轮返工已经发生，整体仍有明显的可避免往返，因此评为8分。

对应记录：第2、3、8、9、10、11轮及结束反馈。

## 与体验评价的汇总

过程评价48/60，学习体验26/40，两项相加，总分为**74/100**。
