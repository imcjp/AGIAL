# P09 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 8/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：8/15

评价总结：两次求和及子塔截取有依据，一般空间排除仍缺关键连接。

教师说明了路径加法、互异数取等、侧塔下界和完整子塔的截取，五层图中右侧格子的父格也得到具体核查。但第14轮推广时，只称旁格若在侧区，其父格就会“太靠左”或“太靠右”，没有说明侧区边界如何限制这个父格的位置，以及该限制为何使其无法走到最后一对的父格。学生对五层右侧的核验不能覆盖任意层的左右两侧，后续也未补出这项连接。第二次求和依赖的空间前提仍有实质解释缺口，评为8分。

对应记录：第5、6、7、8、9、10、11、14、15轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师针对学生希望先算具体数、担心重复及看不清区域的表达，改用小塔、代换和标图。学生要求合并说明后也得到回应；早期宽问与零碎检查说明整体仍有失配，评为14分。

对应记录：第1、3、4、5、6、11、12、14、15轮。

## P3 有依据的自主探究支持：15/15

评价总结：学生对计数和区域的审查实际改变了后续任务与说明。

教师确认学生一次试摆失败所能排除的范围，接着让其选择并连接加法等式、检查加数是否重复。学生提出区域成员的疑问后，教师用图提供子格闭合的检查标准，再接续其两条路线和父格核验。侧塔规模与下界由学生推导，教师核验计算，并回应学生关于截取子塔的边界检查。学生参与了判断、证据审查和结论条件的限定，评为15分。

对应记录：第1、2、3、6、7、10、11、12、13、14、15轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

第3轮流程故障中断支持，第4轮再次宽问，第13轮逐格追问使学生感到零碎。第14轮合讲虽修复后段负担，仍不能抵消前面的往返，评为8分。

对应记录：第3、4、5、6、7、11、12、13、14、15轮。

## 与体验评价的汇总

过程评价45/60，学习体验30/40，两项相加，总分为**75/100**。
