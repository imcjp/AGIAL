# P09 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **52/60** |

## P1 概念理解的引导质量：15/15

评价总结：记录格的后代范围给出了侧区分离的理由，并支撑最终下界。

第6轮明确四层例子两侧各为一个单格，同时用左右底格总数说明边缘位置仍有足够大的侧区。第8轮从路径父格的可达列号出发，分别证明左、右子格的底层后代包含最后一对中的哪一列，与侧塔仅覆盖外侧底格的范围作比较。第9轮核验学生串联的取等、空间分离和第二次求和，并保留列号式作为证明依据，评为15分。

对应记录：第3、4、5、6、7、8、9轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师按请求用四层图解释加数，再根据位置质疑展开左右子格的范围。具体反馈说明帮助有效；错误小例子和首次省略的理由使帮助并非始终连贯，评为14分。

对应记录：第1、3、4、5、6、7、8、9轮。

## P3 有依据的自主探究支持：15/15

评价总结：学生提出的区域与理由核查被采纳，并用于形成完整论证。

学生逐项检查小塔的成员、边缘位置和旁格的排除理由，教师将这些核查转化为两侧区域定义及可逐项检验的后代区间说明。数值下界由学生完成，最终反证也由学生自行串联；教师核验其论证，并区分借助列号式说明理由与脱离材料独立写出证明。学生的证据要求影响了主张的表达和依据，评为15分。

对应记录：第2、3、4、5、6、7、8、9轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

支持故障进入教学、小例子错误以及范围理由省略，分别造成中断和回问。后段分情形解释有组织作用，但完整窗口的额外负担明显，评为8分。

对应记录：第3、4、5、6、7、8、9轮。

## 与体验评价的汇总

过程评价52/60，学习体验33/40，两项相加，总分为**85/100**。
