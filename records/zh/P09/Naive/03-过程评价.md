# P09 · Naive：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

端点位置、小塔穷尽性及区域大小的说法先后需要修正，最终说明了两次求和和侧区的联系。互动澄清了主要断点，但相关概念在不同表示中多次变化，评为14分。

对应记录：第2、3、4、5、6、7轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师根据学生要求改用具体例子和位置核对，后续说明解决了部分疑问。前面的例子和区域表述又制造新问题，帮助的整体协调仍有限，评为14分。

对应记录：第2、4、5、6、7轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生对端点、枚举和区域的质疑获得接续，证据影响了后续解释。教师提供的判断依据需要数次修补，尚不足以将全部过程评为连贯探究，评为14分。

对应记录：第2、3、4、5、6、7轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生需要反复回看例子、校正位置并区分区域层数与格子数量。最终说明可用，整段仍有明显的可避免返工，评为8分。

对应记录：第2、3、4、5、6、7轮。

## 与体验评价的汇总

过程评价50/60，学习体验30/40，两项相加，总分为**80/100**。
