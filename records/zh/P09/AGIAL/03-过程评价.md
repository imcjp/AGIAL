# P09 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **52/60** |

## P1 概念理解的引导质量：15/15

评价总结：共同父格与侧区后代的两组步数被明确区分，空间依据接上了数值反证。

教师先说明每层一个加数及路径部分和的区别，再以六层具体位置解释侧区成员必须保留完整的下方子格。第7轮分别数清父格到倒数第二层、当前层到底层的步数，由此推出旁格范围和同层侧区边界。学生随后代入六层核验，结果与一般关系一致；完整子塔的截取条件也得到说明。两次求和所需的对象、位置和条件能够对应核查，评为15分。

对应记录：第1、2、3、4、5、6、7轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师沿用学生的分层记账，先解释具体六层位置，再按求助给一般关系。学生要求减少编号后，教师去掉额外符号重新说明，帮助有效；原步数表述曾妨碍当前理解，评为14分。

对应记录：第1、2、3、4、5、6、7轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生判断部分和、侧区归属、一般理由和最终下界，并主动检查步数。教师区分路径与旁格的不同证据，明确修正受影响部分，保留学生计算和结论，探究连贯，评为15分。

对应记录：第1、2、3、4、5、6、7轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

位置与大小先后讲解有助于跟进，但第6轮的起止层错误使学生必须再核步数，第7轮重新展开整段列号说明。修复充分，返工仍是可避免负担，评为8分。

对应记录：第1、2、3、4、5、6、7轮。

## 与体验评价的汇总

过程评价52/60，学习体验34/40，两项相加，总分为**86/100**。
