# P07 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师明确区分中间路径数与加数，用允许重复的变式说明下界条件，再以连续左走和一般列号解释侧区分离。第二次下界及截取完整子塔均有依据，评为15分。

对应记录：第2、3、5、6、7轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

学生要求一次一个方向，教师先解释加法，再给条件变式和侧区小图；追问连续左走时先回应该情形，再说明任意路径。帮助与学生当前计算、位置和概括需要相接，评为15分。

对应记录：第2、3、4、5、6、7轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生实际检验重复条件、计算侧区规模与第二次下界，教师核验其推理并保留求助空间。最后区分能串起数值矛盾与仍需借助列号说明的部分，贡献和帮助来源清楚，评为15分。

对应记录：第1、2、3、4、5、6、7轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

具体图先解决混淆，一般式只在学生追问任意路径后展开。最后沿用已完成的数值计算，仅补截取条件，没有重讲整套证明，评为15分。

对应记录：第2、3、4、5、6、7轮。

## 与体验评价的汇总

过程评价60/60，学习体验31/40，两项相加，总分为**91/100**。
