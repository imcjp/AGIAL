# P07 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 14/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **50/60** |

## P1 概念理解的引导质量：14/15

评价总结：通过实际互动贯通相关概念、理由与条件，澄清关键断点。

侧区宽度计算、图示及行号先后需要修正，后段给出的坐标关系与一般论证可以衔接。关键知识得到澄清，但同一关系在多种表示间不够稳定，评为14分。

对应记录：第2、3、5、6、7、8、9轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

教师根据学生对图与位置的疑问调整说明，后续一般式提供了可核查依据。前面的调整数次又产生新疑问，局部帮助有作用，完整协调仍有限，评为14分。

对应记录：第1、4、7、8、9轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生提出计算和位置反例，教师接受并据此修正，实际贡献影响了讨论。部分后续任务所依赖的对象仍需先行校正，评为14分。

对应记录：第1、2、3、6、7、8、9轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

算式、黑白图、行号与侧区范围几次变更，学生必须反复回到原图核对。后段清楚的坐标不能抹去这些返工，评为8分。

对应记录：第2、3、4、5、6、7、8、9轮。

## 与体验评价的汇总

过程评价50/60，学习体验28/40，两项相加，总分为**78/100**。
