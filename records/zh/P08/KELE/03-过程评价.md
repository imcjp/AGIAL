# P08 · KELE：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 14/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **51/60** |

## P1 概念理解的引导质量：15/15

评价总结：侧区的准确范围与加数位置得到对应，结论的使用边界明确。

第3轮教师确认最后一对底格及其倒数第二层父格的位置，给出左右侧区的行列条件，再从共同父格的可达范围推出旁格所在区间，逐边比较得到不相交关系。第4轮核验学生的侧塔高度和互异数求和，并把求和终点仍属于原塔这一事实与全塔上界连接起来。对一般层数，明确保留“未得矛盾不能推出存在”的边界，评为15分。

对应记录：第1、2、3、4轮。

## P2 基于学习证据的支持适配：14/15

评价总结：精准匹配有具体学习证据与实际互动支持，教师依据可见需要改变或保留合适帮助；不要求再增加回合。

坐标说明回应了学生对侧区的明确疑问，后续反馈表明帮助有效。学生已完成上下界比较后，教师又要求解释已使用的上界，没有充分沿用其工作，评为14分。

对应记录：第1、2、3、4轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生实际推导取等、审查位置并完成第二次求和，教师认真核对。末尾再问已完成的上界理由，提供的判断机会没有新增用途；评为14分。

对应记录：第1、2、3、4轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

先定位再比较数值的组织可用，但最后重复检查学生已经说明的上界，学生明确表示无需再问。完整窗口存在可避免的确认往返，评为8分。

对应记录：第1、2、3、4轮。

## 与体验评价的汇总

过程评价51/60，学习体验34/40，两项相加，总分为**85/100**。
