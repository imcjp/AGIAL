# P08 · StratL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 8/15 |
| P3 有依据的自主探究支持 | 14/15 |
| P4 教学推进与负担控制 | 8/15 |
| **过程总分** | **45/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

最终用共同父格坐标补严旁格范围，接上取等、侧塔求和和三层边界。学生给出的高度与计算经教师核对，必要条件得到说明，评为15分。

对应记录：第3、4、5、6、7轮。

## P2 基于学习证据的支持适配：8/15

评价总结：基本有效但有影响当前需要的重要失配。

第5轮已要求起点和示意，第6轮又要求高度与取法，教师仍主要用追问交付。最后的坐标说明有效，但关键帮助明显延迟，评为8分。

对应记录：第3、5、6、7轮。

## P3 有依据的自主探究支持：14/15

评价总结：邀请转化为有依据的实际判断参与；教师开放而严谨地接续有关问题、指标或证据的贡献，并使其影响推进。

学生的取等、位置检查和下界计算得到核对，实质贡献影响了推进。宽泛追问曾使其在缺少起点时寻找目标，后段支持才变得可开展，评为14分。

对应记录：第1、2、3、4、5、6、7轮。

## P4 教学推进与负担控制：8/15

评价总结：任务能完成，但存在实质冗余、跳跃或可避免绕行。

学生多次重申需要具体帮助，必须猜测教师所指的区域。最后集中说明减少了后续拼接，却没有消除前面的无效回问，评为8分。

对应记录：第2、3、4、5、6、7轮。

## 与体验评价的汇总

过程评价45/60，学习体验27/40，两项相加，总分为**72/100**。
