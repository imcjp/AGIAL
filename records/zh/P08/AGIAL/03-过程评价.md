# P08 · AGIAL：过程评价

本评价依据既定量规分析教学过程中呈现的教师支持。

## 指标与评分

各指标满分15分，四项等权相加，过程评价满分60分。

| 指标 | 评分 |
| --- | ---: |
| P1 概念理解的引导质量 | 15/15 |
| P2 基于学习证据的支持适配 | 15/15 |
| P3 有依据的自主探究支持 | 15/15 |
| P4 教学推进与负担控制 | 15/15 |
| **过程总分** | **60/60** |

## P1 概念理解的引导质量：15/15

评价总结：形成有理由、有边界、可复用的理解依据；完整窗口支持，不能只补总结口号。

教师把大数层数限制接到单条路径求和，核对学生的底层后代区间证明，并给出一般下界及小规模边界。最大数已被占用的细节也有明确用途，知识依据完整且可迁移，评为15分。

对应记录：第2、3、4轮。

## P2 基于学习证据的支持适配：15/15

评价总结：把局部帮助连贯衔接回当前完整理解任务，考虑已有帮助，不靠轮数或撤架升级。

学生希望自己推进时只给局部方向，指出多条路径可能合并后改为一条路径；请求核对证明与适用界限时再展开。已有贡献被持续沿用，帮助与完整任务协调，评为15分。

对应记录：第1、2、3、4轮。

## P3 有依据的自主探究支持：15/15

评价总结：相关判断、证据审查与主张修订形成连贯探究，语言支持参与且保持自主性。

学生独立形成区间论证、计算矛盾并审查小规模条件，教师核验而不接管。最后关于最大数占用的提示留下了有依据的实质判断，支持学生进一步限定结论，评为15分。

对应记录：第1、2、3、4轮。

## P4 教学推进与负担控制：15/15

评价总结：完整任务中表达与活动连贯，复杂处讲透、明确处不纠缠，精简不遗漏或转嫁负担。

教师没有重复学生已完成的推导，表格只服务其主动提出的边界检查。复杂的区间关系保留理由，明确的计算简要确认，完整推进没有明显无效往返，评为15分。

对应记录：第2、3、4轮。

## 与体验评价的汇总

过程评价60/60，学习体验39/40，两项相加，总分为**99/100**。
