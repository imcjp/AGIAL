# AGIAL 实验记录

[English](README.md) · [实验记录索引](docs/SESSION_INDEX.md) · [评分表](analysis/scores.csv)

本仓库提供论文《AGIAL：面向自主学习的智能体引导探究框架》的反帕斯卡三角形实验记录，包括教学逐字稿、学习体验访谈和过程评价。

**中文版是实验分析所用的原始实验数据，英文版是同一批记录的译文。** 实验包含 10 名受试者，每名受试者完成五种方法，共 50 组交互。
