# AGIAL Experimental Records

[中文说明](README.zh-CN.md) · [Session index](docs/SESSION_INDEX.md) · [Scores](analysis/scores.csv)

This repository accompanies *AGIAL: An Agent-Guided Inquiry Framework for Autonomous Learning*. It contains the experimental records from the anti-Pascal triangle study, including teaching transcripts, participant experience interviews, and process evaluations.

**The Chinese-language records are the original experimental data used for analysis. The English-language records are translations of the same sessions.** The study includes 10 participants who each completed five methods, for a total of 50 sessions.
